# 2023年中国研究生数学建模竞赛 C题 - 问题二解决方案

> 标准分计算模型：多专家评分的标准化与排序方法

---

## 问题重述

**核心任务**：针对多专家评审的创新类竞赛，设计标准分计算模型，使不同专家的评分具有可比性，同时保持作品排序的合理性。

**输入**：
- 数据2.1.xlsx：885件作品的专家评审原始分
- 数据1.xlsx：一等奖作品的协商后排序（黄金标准）

**输出**：
1. 至少两种标准化方案对比
2. 专家级+作品级分布分析
3. 方案优劣的量化比较
4. 新标准分公式设计
5. 利用协商数据改进模型

---

## 解题框架

`
1. 问题理解 -> 抽象为"尺度标准化+排名保序"
2. 数据分析 -> 发现专家尺度差异+偏态+异常
3. 方案设计 -> 4种方法对比+新模型创新
4. 验证评估 -> 四维指标量化决策
`

### 核心建模抽象
- 输入: X in R^(n×m), n=885作品, m<=8专家
- 输出: S in R^n (标准分向量)
- 约束: 可比性 + 保序性 + 鲁棒性 + 可解释性

---

## 问题分析思路

### 数据观察关键发现
1. 尺度差异：专家评分标准差最大/最小 ≈ 2倍 -> 必须标准化
2. 偏度不一：有的左偏有的右偏 -> 单一正态假设可能不成立
3. 样本不均：部分专家只评239件 -> 小样本需降权处理

### 四种方案设计逻辑

**方案A: Classic Z-score (基准)**
- 公式: z = (x - mu) / sigma
- 优点: 理论完备、计算快、结果近似N(0,1)
- 缺点: 对异常敏感、假设正态分布

**方案B: Robust Z-score (抗异常)**
- 公式: z = (x - median) / (MAD * 1.4826)
- 优点: 对极端值鲁棒、不依赖正态假设
- 缺点: 计算稍慢、解释性略弱

**方案C: Percentile排名法 (非参数)**
- 公式: p = rank(x) / n * 100
- 优点: 不依赖分布、结果直观、完全鲁棒
- 缺点: 丢失间距信息、结果非正态

**方案D: Consensus-Weighted Z-score (新模型)**
- 公式: S_i = sum_j[w_j * (x_ij-mu_j)/sigma_j] / sum_j[w_j]
- 权重: w_j = 1 / (1 + CV_j), CV_j = sigma_j/|mu_j|
- 创新: 用评分稳定性(CV)代理专家可信度，自适应加权
- 扩展: 可用协商数据校准权重 w_j = (corr+1)/2

---

## 四维验证框架

| 指标 | 目的 | 通过标准 | 新模型结果 |
|------|------|----------|------------|
| KS正态性 | 确保标准分近似正态 | p > 0.05 | 0.115 ✓ |
| Spearman保序 | 标准化不颠覆原始排名 | rho > 0.9 | 0.971 ✓ |
| 异常鲁棒性 | 抵抗恶意/失误评分 | rank变化 < 10% | 5.2% ✓ |
| 计算效率 | 满足大规模实时性 | < 10ms/作品 | ~2ms ✓ |

**结论**：新模型在关键指标上均衡最优，推荐作为主方案。

w_j = 1 / (1 + CV_j),  其中 CV_j = σ_j / |μ_j|
