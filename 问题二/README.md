1. 不再把“专家一/专家二”等位置列当作同一位专家。程序会把每条记录展开为“阶段、专家编码、原始分”的长表，再按 `阶段 + 专家编码` 计算均值、标准差、中位数、MAD 和权重。
2. 第二阶段读取专家编码和原始分配对：`(23,24)、(27,28)、(31,32)`，不再混用标准分列或把专家编码当成数值。
3. 接入 `数据1.xlsx`：只取一等奖作品，使用 `专家原始分` 与 `-协商排名` 的 Spearman 相关校准权重，避免“名次越小越好”导致方向反转。
4. KS、Spearman、Top-50 扰动鲁棒性、运行时间均由代码真实计算，不再写死雷达图分数。

## 核心公式

对作品 `i`，专家 `e` 在阶段 `s` 的原始分为 `x_i,s,e`。先按 `阶段 + 专家编码` 统计：

```text
z_i,s,e = (x_i,s,e - mu_s,e) / sigma_s,e
```

CV 基础权重：

```text
w_cv_s,e = 1 / (1 + sigma_s,e / |mu_s,e|)
```

数据1校准权重：

```text
c_s,e = shrink * ((corr(score_s,e, -rank) + 1) / 2 - 0.5) + 0.5
```

其中 `rank` 越小代表协商排序越好，所以使用 `-rank` 保持方向一致。最终权重：

```text
w_s,e = w_cv_s,e * c_s,e
```

作品标准分：

```text
S_i = sum(w_s,e * z_i,s,e) / sum(w_s,e)
```
