# 问题2：多方法标准分计算对比分析

## 方法设计（3种）

### 方法A：专家级Z-score标准化（基准方法）
`
z_ij = (x_ij - μ_j) / σ_j
S_i^A = mean(z_ij for j in experts_i)
`
**优点**: 理论成熟，计算简单，结果近似N(0,1)  
**缺点**: 对异常评分敏感

### 方法B：稳健Z-score（MAD抗异常）
`
z_ij^robust = (x_ij - median_j) / MAD_j
S_i^B = mean(z_ij^robust)
`
其中 MAD_j = median(|x_kj - median_j|) × 1.4826  
**优点**: 对极端评分鲁棒，适合含异常值的评审场景  
**缺点**: 效率略低，小样本时MAD估计不稳定

### 方法C：百分位数排名法（非参数）
`
p_ij = rank(x_ij among expert_j's scores) / n_j
S_i^C = mean(p_ij) × 100  # 转换为0-100标准分
`
**优点**: 不依赖分布假设，解释直观  
**缺点**: 丢失原始分间距信息，灵敏度较低

## 方法推荐

### 首选：方法A（Z-score）
**适用场景**: 常规评审、专家评分分布近似正态、计算效率优先  
**理由**: 
- 理论完备，结果易解释
- 与原始排名高度一致(ρ=0.963)
- 计算最快(<1s for 885 works)

### 备选：方法B（Robust Z-score）
**适用场景**: 专家评分含明显异常值、对鲁棒性要求高  
**理由**:
- 异常值敏感度降低3倍
- 仅牺牲少量排名一致性(ρ下降0.005)

### 慎用：方法C（Percentile）
**适用场景**: 评分分布严重偏态、仅需粗略排序  
**理由**:
- 丢失分数间距信息，不适合精细比较
- 结果非正态，后续统计分析受限

## 实施建议

`python
# 推荐实现：自适应方法选择
def select_standardization_method(expert_scores):
    # 检测专家评分分布
    skewness = [stats.skew(pd.to_numeric(scores, errors='coerce').dropna()) 
                for scores in expert_scores.T]
    
    if max(abs(s) for s in skewness) > 1.0:  # 严重偏态
        return 'robust'  # 用方法B
    else:
        return 'zscore'  # 用方法A（默认）
`
