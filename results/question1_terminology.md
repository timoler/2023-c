# 问题1：术语与符号定义表

## 决策变量
| 符号 | 含义 | 取值范围 | 单位 |
|------|------|----------|------|
| {ij}$ | 作品 | $\{0,1\}$ | - |
| {ik}$ | 作品 | $\{1,2,...,125\}$ | 专家ID |

## 参数定义
| 符号 | 含义 | 典型值/范围 | 来源 |
|------|------|-------------|--------|
| $ | 作品总数 | 3000 | 题目给定 |
| $ | 专家总数 | 125 | 题目给定 |
| $ | 每作品需评审专家数 | 5 | 题目给定 |
| {\min}$ | 专家最小工作量 | $\lfloor NK/M \rfloor - 2$ | 均衡约束 |
| {\max}$ | 专家最大工作量 | $\lceil NK/M \rceil + 2$ | 均衡约束 |
| $\delta$ | 防作弊最小分差阈值 | 5-10分 | 经验设定 |
| $ | 专家 | $\mathbb{R}^d$ | 专家档案 |
| $ | 作品 | $\mathbb{R}^d$ | 作品摘要提取 |

## 目标函数组件
| 组件 | 数学表达 | 物理含义 |
|------|----------|----------|
| 工作量均衡项 | $\sum_j (L_j - \bar{L})^2$ | 专家负载方差，越小越公平 |
| 评分多样性项 | $\sum_i (1 - \frac{\max_j s_{ij} - \min_j s_{ij}}{S_{\max}-S_{\min}})$ | 作品获评分的离散程度 |
| 防作弊惩罚项 | $\sum_{i,j<k} \mathbb{I}(|s_{ij}-s_{ik}|<\delta) \cdot x_{ij}x_{ik}$ | 同作品专家评分过近的惩罚 |
| 专业匹配项 | $-\sum_{i,j} \text{cosine}(v_i, w_j) \cdot x_{ij}$ | 专家-作品专业契合度（负号表示最大化） |

## 约束条件
| 约束类型 | 数学表达 | 业务含义 |
|----------|----------|----------|
| 作品评审数 | $\sum_j x_{ij} = K, \forall i$ | 每作品恰好5专家评审 |
| 专家负载上限 | $\sum_i x_{ij} \leq L_{\max}, \forall j$ | 专家不过劳 |
| 专家负载下限 | $\sum_i x_{ij} \geq L_{\min}, \forall j$ | 专家不闲置 |
| 防作弊约束 | $|s_{ij} - s_{ik}| \geq \delta \cdot x_{ij}x_{ik}, \forall i,j\neq k$ | 同作品专家评分需有合理差异 |
| 专业匹配约束 | {ij} = 0$ if $\text{cosine}(v_i,w_j) < \theta$ | 专家只评专业相关作品 |
| 互斥约束 | {ij} + x_{ik} \leq 1$ if $\text{conflict}(j,k)$ | 有冲突的专家不评同一作品 |

## 评价指标
| 指标名称 | 计算公式 | 优秀阈值 |
|----------|----------|----------|
| 工作量均衡度 |  - \frac{\text{std}(L_j)}{\text{mean}(L_j)}$ | >0.95 |
| 评分多样性均值 | $\frac{1}{N}\sum_i \text{diversity}_i$ | >0.7 |
| 防作弊达标率 | $\frac{|\{i: \min_{j\neq k}|s_{ij}-s_{ik}|\geq\delta\}|}{N}$ | >99% |
| 专业匹配度均值 | $\frac{1}{NK}\sum_{i,j} \text{cosine}(v_i,w_j)x_{ij}$ | >0.6 |
| 求解耗时 | {\text{solve}}$ (秒) | <300s |

| $\theta$ | 专业匹配阈值 | 0.5 |
| $\delta$ | 防作弊分差阈值 | 8分 |
| $ | 模拟退火初始温度 | 100 |
