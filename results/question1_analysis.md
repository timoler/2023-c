# 2023-C题 问题1：作品-专家分配优化模型

## 问题重述
> 3000支参赛队，125位评审专家，每作品需5位专家评审。设计最优「作品-专家」分配方案，满足：
> 1. 专家工作量均衡（避免过载/闲置）
> 2. 作品评分可比性（不同专家评同一作品时，评分差异需合理）
> 3. 防作弊约束（相同作品被不同专家评的分差不能过小，避免
商量好）
> 4. 实施可行性（考虑专家专业领域、时间冲突等现实约束）

## 核心矛盾
**资源约束下的多目标平衡**: 
- 目标A: 最小化专家工作量方差（公平性）
- 目标B: 最大化作品评分多样性（防作弊）  
- 目标C: 最小化分配计算复杂度（可实施性）

## 建模思路：0-1整数规划 + 启发式后处理

### 决策变量
`
x_{ij} = 1, 若作品i分配给专家j评审
       = 0, 否则
`

### 目标函数（加权多目标）
`
min  α·∑_j (L_j - L̄)² + β·∑_i (1 - diversity_i) + γ·∑_{i,j,k} penalty_{ijk}
`
其中:
- L_j = ∑_i x_{ij}: 专家j的工作量
- diversity_i = 1 - (max_score - min_score)/range: 作品i的评分多样性
- penalty_{ijk}: 专家j,k同评作品i时的相似度过高惩罚

### 约束条件
`
1. 每作品恰好5专家评审: ∑_j x_{ij} = 5, ∀i
2. 专家工作量上限: ∑_i x_{ij} ≤ L_max, ∀j  
3. 专家工作量下限: ∑_i x_{ij} ≥ L_min, ∀j
4. 防作弊约束: |score_j - score_k| ≥ δ, ∀i, ∀j≠k where x_{ij}=x_{ik}=1
5. 专业匹配约束: x_{ij}=0 if expert_j not qualified for work_i
6. 互斥约束: x_{ij}+x_{ik}≤1 if expert_j,k have conflict
`

### 求解策略
1. **精确求解**（小规模）: Gurobi/CPLEX求解0-1规划
2. **启发式求解**（3000×125大规模）: 
   - 阶段1: 贪心初始化（按专业匹配度分配）
   - 阶段2: 局部搜索优化（交换分配对，改善目标函数）
   - 阶段3: 模拟退火跳出局部最优

## 评价指标体系
| 指标 | 计算公式 | 期望值 |
|------|----------|--------|
| 工作量均衡度 | 1 - std(L_j)/mean(L_j) | >0.95 |
| 评分多样性 | mean(diversity_i) | >0.7 |
| 防作弊达标率 | #满足|Δscore|≥δ的作品 / 3000 | >99% |
| 计算耗时 | 求解时间(秒) | <300s |
| 方案可行性 | 约束违反数 | 0 |
