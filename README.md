# 2023 年研究生数学建模 C 题

大规模创新类竞赛评审方案研究，供队员共享题目、数据、代码与实验结果。

## 当前进度

第一问已完成均衡贪心分配及 100 次随机均衡基线实验，论文中的模型表述、实施细节和最优性讨论尚待完善。当前贪心解未证明为全局最优解。

- 3000 份作品，每份由 5 位不同专家评审。
- 125 位专家，每位评审 120 份作品。
- 专家对共同评审次数为 3～5 次，97.26% 的专家对交叉 3～4 次。
- 交叉次数标准差约 0.4088；随机基线 100 次平均约 1.9039。

## 读取与运行

队员接受私有仓库邀请后，可以在 GitHub 页面浏览文件，或通过 Code → Download ZIP 下载；使用 Git 的队员可以克隆仓库。

在项目目录安装依赖并运行：

```powershell
python -m pip install -r requirements.txt
python 专家评审分配.py
python 随机均衡分配基线.py
```

运行会覆盖目录内对应的 CSV 和 PNG 结果。绘图脚本会弹出窗口，关闭窗口后继续。中文显示需要 Microsoft YaHei 或 SimHei 字体。

随机基线脚本中的贪心对比值为手动填写的近似值；更改贪心算法后，需要同步更新这些值。贪心脚本尚无尾部分配可行性保护，修改参数或随机种子时需要重新验证约束。
